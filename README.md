# Тесты по русскому языку · 5–11 классы

Интерактивные тесты к урокам недели 09.11–15.11.2026 — **«Учительская» / Арина Галицкая**.

**Онлайн:** https://prouchitelskaya.github.io/russian-tests-09-11-15-11-2026/

## Что внутри

Одна страница — семь блоков тестов, по одному на класс. В каждом классе **20 вопросов** с мгновенной проверкой и объяснением каждого ответа.

| Класс | Тема |
|---|---|
| 5 | Синтаксис: словосочетание и предложение |
| 6 | Разносклоняемые и несклоняемые существительные |
| 7 | Наречие: образование, разбор, правописание |
| 8 | Определение, приложение, дополнение |
| 9 | Разбор СПП и придаточные места |
| 10 | Приставки, задание 10, Ъ и Ь |
| 11 | Обобщающие слова, сочинение, обособление |

Прямые ссылки на класс: `…/#g5`, `…/#g6`, … `…/#g11`.

## Технически

- Статический сайт: HTML + CSS + vanilla JS, без сборки и зависимостей.
- `data.js` — банк вопросов (JSON). Авторская конвенция: правильный ответ всегда `options[0]`, `answer: 0`; на странице варианты перемешиваются.
- Прогресс (лучший результат по классу) хранится в `localStorage` (`rustests20261109:v1`).
- Светлая/тёмная тема — по `prefers-color-scheme`.
